11 Part 1 — Python MapReduce Without Hadoop

11.1 Learning Objectives

In this practical, you will learn the MapReduce programming model by implementing it entirely in Python.

By the end of this practical, you will be able to:

  • understand the MapReduce programming model;
  • implement a Mapper;
  • implement a Shuffle operation;
  • implement a Reducer;
  • process text data using MapReduce;
  • process CSV data using MapReduce;
  • perform counting, summation, averaging, and ranking;
  • compare MapReduce with Pandas;
  • process progressively larger datasets;
  • understand why distributed frameworks such as Hadoop are useful.

Important: Hadoop is not used in Part 1. You will first understand the MapReduce programming model using Python alone.

13 2. Understanding the MapReduce Model

Before writing the first program, understand the basic MapReduce workflow.

                 INPUT DATA
                     |
                     v
                +----------+
                |  MAPPER  |
                +----------+
                     |
                     v
                KEY-VALUE PAIRS
                     |
                     v
                +----------+
                | SHUFFLE  |
                +----------+
                     |
                     v
                GROUPED VALUES
                     |
                     v
                +----------+
                | REDUCER  |
                +----------+
                     |
                     v
                   OUTPUT

The three important stages are:

13.0.1 Mapper

Converts input records into key-value pairs.

13.0.2 Shuffle

Groups values belonging to the same key.

13.0.3 Reducer

Aggregates the grouped values.

For example, for Word Count:

Input:

Python Hadoop Python

Mapper:

Python  -> 1
Hadoop  -> 1
Python  -> 1

Shuffle:

Python  -> [1, 1]
Hadoop  -> [1]

Reducer:

Python  -> 2
Hadoop  -> 1

In Hadoop, the framework performs the Shuffle phase.

In this practical, you will implement the Shuffle phase yourself so that you can understand exactly what happens.

15 4. Implement the Mapper

The Mapper should convert every word into:

(word, 1)

For example:

Python Python Hadoop

becomes:

("python", 1)
("python", 1)
("hadoop", 1)

Run the following cell.

def word_count_mapper(lines):
    mapped_data = []

    for line in lines:

        words = line.strip().lower().split()

        for word in words:
            mapped_data.append((word, 1))

    return mapped_data

16 5. Implement the Shuffle

The Shuffle phase groups values having the same key.

For example:

python -> 1
python -> 1
python -> 1

becomes:

python -> [1, 1, 1]

Run:

from collections import defaultdict

def shuffle(mapped_data):

    grouped_data = defaultdict(list)

    for key, value in mapped_data:
        grouped_data[key].append(value)

    return grouped_data

17 6. Implement the Reducer

The Reducer receives:

key -> [values]

and calculates the final result.

For Word Count:

python -> [1, 1, 1]

becomes:

python -> 3

Run:

def word_count_reducer(grouped_data):

    result = {}

    for key, values in grouped_data.items():

        result[key] = sum(values)

    return result

19 8. Build a Complete MapReduce Function

You have implemented Mapper, Shuffle, and Reducer separately.

Now combine them into one function.

def map_reduce(
    data,
    mapper_function,
    reducer_function
):

    # MAP
    mapped = mapper_function(data)

    # SHUFFLE
    grouped = shuffle(mapped)

    # REDUCE
    result = reducer_function(grouped)

    return result

28 17. Demo 3 — Average Using MapReduce

28.1 Objective

You will now perform numerical aggregation.

Answer:

What is the average PageValues for each VisitorType?

The MapReduce operation is:

Mapper:

VisitorType -> PageValues

        ↓

Shuffle:

VisitorType -> [PageValue1, PageValue2, ...]

        ↓

Reducer:

VisitorType -> Average(PageValues)

29 18. Implement the Mapper

def page_value_mapper(df):

    mapped = []

    for _, row in df.iterrows():

        visitor_type = row["VisitorType"]
        page_value = row["PageValues"]

        mapped.append(
            (visitor_type, page_value)
        )

    return mapped

30 19. Implement the Average Reducer

def average_reducer(grouped_data):

    result = {}

    for key, values in grouped_data.items():

        if len(values) > 0:

            result[key] = (
                sum(values) / len(values)
            )

    return result

def country_revenue_mapper(df):

    mapped = []

    for _, row in df.iterrows():

        country = row["Country"]
        revenue = row["Revenue"]

        mapped.append(
            (country, revenue)
        )

    return mapped

def sum_reducer(grouped_data):

    result = {}

    for key, values in grouped_data.items():

        result[key] = sum(values)

    return result

58 46. Advanced Concept — Combiner

In a distributed MapReduce system, sending every Mapper output through the network can be expensive.

A Combiner can perform local aggregation before the Shuffle phase.

For example:

Mapper output:

python -> 1
python -> 1
python -> 1
python -> 1

A Combiner can transform this locally into:

python -> 4

Implement a simple Combiner:

def combiner(mapped_data):

    local_counts = defaultdict(int)

    for key, value in mapped_data:

        local_counts[key] += value

    return list(
        local_counts.items()
    )

Test it:

combined_data = combiner(

61 49. Important Observation

Do not assume that Python MapReduce will always be faster than Pandas.

You are currently processing the data on a single machine.

Pandas uses highly optimized internal implementations, whereas our MapReduce implementation is intentionally written in straightforward Python so that the processing model is visible.

The objective of this practical is:

Understand how a data-processing problem can be expressed using Map → Shuffle → Reduce.

The objective is not to demonstrate that manually implemented Python MapReduce is faster than Pandas.
